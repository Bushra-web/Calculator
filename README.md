# 🔢 Math Magician

A small multi-page site built with plain HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies.

## What it does

Math Magician is a 3-page site: a home/about page, a fully working calculator, and a page with a math quote.

## Features

- ✅ Working calculator — add, subtract, multiply, divide, sign toggle, percent, clear
- ✅ Fully responsive — works on desktop, tablet, and mobile
- ✅ Clean, minimal code — no unnecessary classes/ids, easy to read and extend
- ✅ Zero dependencies — just open it and go

## Project structure

```
mathmagician/
├── index.html        Home page
├── calculator.html   Calculator page
├── quote.html         Quote page
├── style.css          Shared styles + responsive rules
└── script.js          Calculator logic
```

## Getting started

1. Download/keep all files in one folder.
2. Open `index.html` in your browser.
3. That's it — nothing to install or build.

## Tech

| Layer | Tool |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (flexbox, grid, media queries) |
| Logic | Vanilla JavaScript |

## Responsive behavior

| Screen size | What changes |
|---|---|
| Wide (desktop) | Full layout, calculator and text side by side |
| ≤ 700px | Nav centers/wraps, cards shrink to fit |
| ≤ 420px | Calculator buttons and screen shrink for small phones |
